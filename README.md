# LorPlugin — «Отголоски Бездны»

Сюжетный плагин для Paper **1.21.11**, построенный вокруг скалка, Древнего города и Хора погребённых душ. Игрок — Слушающий: он проходит 6 глав, копит эхо, борется с заражением, собирает реликвии, переживает Скалк-приливы и в финале призывает Глашатая Бездны.

> Плагин собран и скомпилирован под Paper 1.21.11 (API `1.21.11-R0.1-SNAPSHOT`). По просьбе автора серверный рантайм-тест не запускался — тестируйте на своём сервере.

## Возможности

- **6 глав лора** с целями, наградами и финалом (`chapters.yml`).
- **Эхо** — валюта прогресса: за скалк, мобов, главы, приливы и босса.
- **Переводы эха** между игроками: `/lor pay <ник> <сумма>` (комиссия, лимиты и кулдаун настраиваются).
- **Логи переводов** в `data/payments.log` и просмотр `/lor logs` по отдельному праву `lor.logs` (без `lor.admin`).
- **Встроенный аукцион** `/lor ah`: лоты за эхо, поиск на русском и английском, свои лоты, покупка и снятие, комиссия и лимиты.
- **Заражение скалка** 0–100%: шёпот, тошнота, Тьма, слабость, урон на 100%, очищение эссенцией и Амулетом Тишины.
- **8 кастомных предметов**: осколок эха, резонатор, очищающая эссенция, скалк-клинок, ключ Бездны, Сердце Хора, Амулет Тишины, Фолиант Слушающего.
- **Крафты** с отдельным GUI: `/crafts`, `/recipes`, `/craft` или кнопка «Крафты» в `/lor`.
- **4 кастомных моба**: ползун, эхо-страж, пожиратель эха, скалк-вестник (со своими способностями).
- **Босс «Глашатай Бездны»**: 3 фазы, звуковые лучи, импульсы тьмы, призыв мобов, ударная волна, боссбар.
- **Ритуал 5×5** из скалка и крикунов, призывающий босса.
- **Скалк-прилив** — периодическое мировое событие с расползанием скалка и волнами мобов.
- **Генерация святилищ** в биоме Глубокой Тьмы (готовые ритуальные площадки).
- **GUI**: профиль, главы, кодекс (5 страниц), реликвии, крафты, аукцион, статистика, топ.
- **PlaceholderAPI** (опционально): `%lor_echo%`, `%lor_corruption%`, `%lor_chapter%` и др.
- Сохранение профилей в `plugins/LorPlugin/data/players.yml`, лотов в `data/auction.yml`, логов переводов в `data/payments.log`, автосейв.

## Сборка

Нужны **JDK 21+** и **Maven 3.9+**.

```bash
mvn clean package
```

Готовый файл: `target/LorPlugin-1.0.0.jar`.

## Установка

1. Положите `LorPlugin-1.0.0.jar` в `plugins/`.
2. Запустите сервер Paper 1.21.11.
3. Настройте `plugins/LorPlugin/config.yml` и `messages.yml`.
4. `/lor admin reload` после правок.

## Команды

| Команда | Что делает |
|---|---|
| `/lor` | Главное меню |
| `/lor quests` | Главы и цели |
| `/lor codex` | Кодекс Слушающего |
| `/lor relics` | Реликвии |
| `/lor recipes` | **GUI с крафтами** |
| `/lor stats` | Статистика |
| `/lor top` | Топ по эху |
| `/lor pay <ник> <сумма>` | Перевести эхо другому игроку (`all`, `1.5k`, `2к` тоже работают) |
| `/lor logs [ник] [страница]` | Логи переводов (право `lor.logs`) |
| `/lor ah` | Открыть аукцион |
| `/lor ah search <запрос>` | Поиск лота по названию предмета на русском или английском (Tab подсказывает все блоки и предметы) |
| `/lor ah sell <цена>` | Выставить предмет из главной руки |
| `/lor ah my [страница]` | Свои лоты (клик — снять с продажи) |
| `/lor ah buy <id>` | Купить лот по ID |
| `/lor ah cancel <id>` | Снять свой лот по ID |
| `/lor ritual` | Схема ритуала в чат |
| `/lor hud` | Вкл/выкл HUD |
| `/crafts` | Сразу открыть GUI крафтов (алиасы: `/recipes`, `/craft`) |

### Админ-команды (`lor.admin`)

```text
/lor admin reload
/lor admin event start|stop
/lor admin give <id> [player] [amount]
/lor admin spawn <mob> [amount]
/lor admin boss
/lor admin echo <player> <amount>
/lor admin corruption <player> <amount>
/lor admin chapter <player> <id>
/lor admin complete <player> <id>
/lor admin reset <player>
```

ID предметов: `echo_shard`, `resonator`, `cleansing_essence`, `sculk_blade`, `abyss_key`, `heart_of_choir`, `silence_amulet`, `listener_tome`.

ID мобов: `crawler`, `sentinel`, `devourer`, `herald`.

## Права

- `lor.use` — меню и сюжет (по умолчанию всем).
- `lor.pay` — переводы эха (по умолчанию всем).
- `lor.logs` — просмотр логов переводов (по умолчанию операторам; `lor.admin` не нужен).
- `lor.auction` — доступ к аукциону (по умолчанию всем).
- `lor.admin` — админ-команды (по умолчанию операторам).

## Быстрый чек-лист для теста

```text
/lor admin give abyss_key
/lor admin chapter <ник> 5
/lor admin corruption <ник> 60
/lor admin spawn crawler 3
/lor admin event start
/lor pay <ник> 100
/lor ah sell 250
/lor logs <ник>
```

Ритуал: соберите схему из `/lor ritual` (5×5, катализатор в центре) или найдите сгенерированное святилище в Глубокой Тьме, затем ПКМ резонатором по катализатору. Босс призывается с 5-й главы и требует Ключ Бездны (по умолчанию).

## Конфигурация (кратко)

- `settings.worlds` — список миров (пусто = все).
- `corruption.*` — скорость заражения, порог, урон, очищение.
- `echo.*` — награды эха.
- `payments.*` — включение переводов, лимиты, комиссия и кулдаун.
- `payments.logs.*` — включение журнала и число последних записей в памяти.
- `auction.*` — включение аукциона, лимит лотов, цены, комиссия и запрещённые предметы.
- `mobs.*` — естественный спавн и лимит кастомных мобов.
- `boss.*` — здоровье и урон Глашатая.
- `ritual.*` — требуемая глава, ключ, кулдаун.
- `tide.*` — интервал/длительность прилива и расползание скалка.
- `worldgen.shrines.*` — шанс и высоты святилищ.
- `recipes.*` — включение отдельных крафтов (влияет и на GUI).

```text
├── auction              — лоты, покупка/продажа, auction.yml
├── command              — /lor и /crafts
├── config               — config.yml и messages.yml
├── data                 — профили и сохранение

├── gui                  — все меню, включая крафты
├── integration          — PlaceholderAPI
├── items                — предметы, рецепты, книга рецептов
├── listeners            — блоки, сущности, игрок
├── mechanics            — заражение, мобы, босс, ритуал, прилив, святилища
├── quest                — главы и цели
└── util                 — текст, кулдауны, ключи, русские названия предметов (items-ru.yml)
```
